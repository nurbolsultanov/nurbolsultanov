**[AI Resume-JD Matcher](https://github.com/nurbolsultanov/resume-matcher) - live web app**
Scores resume-JD fit using Claude API and semantic embeddings. Returns match score, missing keywords, suggested bullet rewrites, and gap analysis.

[Live demo](https://resume-matcher-nurbolsultanov.streamlit.app/) · [Repo](https://github.com/nurbolsultanov/resume-matcher)

**[Multi-Entity Retail Analytics](https://github.com/nurbolsultanov/retail-analytics)**
Consolidated sales, margin, and inventory-shrink analysis across a 3-entity, 12-location retail group, unifying two POS systems (Square + PayAnywhere) into one reporting layer. Per-entity and network roll-ups, category margin, and an audit-lens shrink model that separates true loss from receiving variance and count corrections.
Stack: Python, pandas, Plotly, Streamlit, Jupyter
*Synthetic dataset modeled on a real multi-entity retail back-office workflow.*

**[Demand Forecasting + Anomaly Detection](https://github.com/nurbolsultanov/demand-forecasting)**
Time-series forecasting on Rossmann Store Sales (1M rows, 1,115 stores). Three models compared with walk-forward cross-validation: LightGBM reached 8.20% MAPE, roughly 2x better than Prophet (17.16%) and SARIMA (17.95%). Anomaly detection on residuals.
Stack: Prophet, SARIMA, LightGBM, statsmodels, Plotly
